The Taste — GitHub Pages

1. Extract this ZIP on your computer.
2. Upload all extracted files and the assets folder into the root of your GitHub repository.
   index.html must be in the repository root. Upload the extracted files, not the ZIP.
3. In GitHub: Settings > Pages > Build and deployment > Source: Deploy from a branch.
4. Choose main and / (root), then Save. If your branch has another name, choose that branch.
5. Wait for GitHub Pages to show your published URL.

This package contains the exact current website files: 47 dishes, photos for 37 dishes,
prices, original fonts, logo, menu symbols, full-color spices header, and aligned cards.
It works at both a user site and a repository subpath because resource paths are relative.
No installation or build is required.

Open through GitHub Pages to test. Opening index.html directly from your computer
may block loading menu.json in your browser.

If replacing an earlier version, replace index.html, app.js, style.css, menu.json,
symbols.json and the complete assets folder.
